# Demo Notes - Lab 7 Workboard

## Demo Flow

1. Open Workboard home page.
2. Add Todo tasks, change status, filter, and delete.
3. Create Product, edit Product, delete Product.
4. Show Blog preview cards from API.
5. Navigate to Blog page and Blog detail.
6. Navigate to Products route using same integrated shell.

## Why This Design

- Typed modules separate domain logic from UI.
- One workboard improves task context switching.
- Shared layout/navigation gives a consistent user experience.
